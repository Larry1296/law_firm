# Direct prospective-client / proposed-matter entry

The digital lifecycle begins after manual reception and the advocate's brief encounter:

`Prospective client → Proposed matter → Conflict screening → Advocate conflict decision`

The Clients area now provides **New proposed matter / Start conflict check**. An authorised firm owner or advocate selects an existing same-firm prospective/official client or records a minimal firm-managed prospective client with general privacy-notice evidence. Stage B records only the working title, broad instructions, responsible advocate, relevant parties, broad practice area, urgency and known deadline. The existing proposed-matter service creates an atomic `NOT_STARTED` proposal with pending acceptance and no portal account, engagement, case or matter. The user is redirected to the existing conflict-screening page.
